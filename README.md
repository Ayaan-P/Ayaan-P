# Ayaan Pupala

## Fullstack / ML Engineer 

I studied Computer Engineering at UIUC, worked as a federal contractor in DC, and later joined a biotech startup developing deep learning models for early cancer detection. I completed my Master's in AI at Northwestern, refining my expertise in machine learning, automation, and product design.

I'm fascinated by how AI can enhance everyday experiences. This led me to create Dytto — the personal context layer for AI. Dytto collects rich personal context and serves it via API so any AI agent can deliver instantly personalized experiences. Think Plaid for personal context: any AI plugs in, and it knows you like your best friend does.
